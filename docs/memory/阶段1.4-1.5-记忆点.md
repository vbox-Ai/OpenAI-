# 阶段 1.4 + 1.5 记忆点：HostEnv 构造 + FFI 边界

## 做了什么
- 新增 `crates/providers/src/ffi.rs`：
  - `agent2api_providers_init(data_dir, target, loopback_port)` → 构造 HostEnv + EmbeddedHost
  - `agent2api_providers_provider_infos()` → JSON 字符串（ProviderInfo 列表）
  - `agent2api_providers_string_free()` → 释放返回的 C 字符串
  - `agent2api_providers_shutdown()` → 优雅停机
- `lib.rs` 注册 `mod ffi`

## 结果
- ✅ CI run #8 success（宿主桌面 + aarch64-apple-ios 双 check 通过）

## 关键设计
- FFI 字符串契约：Rust 返回 `CString::into_raw` 的 C 字符串，调用方读完调 `string_free` 释放
- 全局 `OnceLock<Arc<EmbeddedHost>>` 持有宿主（进程内单例）
- `loopback_port` 给 OAuth 回调，`target` 填 `aarch64-apple-ios`
