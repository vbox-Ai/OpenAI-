# 阶段 1.6 记忆点：通用控制面分发 + FFI call

## 做了什么
- SDK 新增 `dispatch.rs`：`dispatch_control`（28 个控制面方法的分发，抽自 serve.rs）
- `serve.rs` 的 `handle_control` 改为调用 `dispatch_control`（去重）
- `EmbeddedHost` 新增 `call(method, params)` 方法
- `providers/ffi.rs` 新增 `agent2api_providers_call`（通用 FFI 调用，JSON 信封返回）
- `ffi.rs` 新增全局 `tokio::runtime::Runtime`（`block_on` 桥异步）

## 结果
- ✅ CI run #10 success（宿主桌面 + aarch64-apple-ios 双 check 通过）

## 关键设计
- `dispatch_control` 返回 `Result<Value, String>`，不负责回复：
  stdio 模式映射成 WireError，FFI 模式包成 JSON 信封
- FFI `call` 返回 `{"ok":true,"result":<value>}` 或 `{"ok":false,"error":"<msg>"}`
- 全局 `OnceLock<Runtime>` 提供 `block_on`（FFI 是同步函数，桥异步）
