# 阶段 1.3 记忆点：EmbeddedHost

## 做了什么
- SDK 新增 `crates/provider-sdk/src/embedded.rs`：`EmbeddedHost`（无 stdio 宿主骨架）
- `lib.rs` 注册 `pub mod embedded` + `pub use embedded::EmbeddedHost`

## 结果
- ✅ CI run #6 success（宿主桌面 + aarch64-apple-ios 双 check 通过）

## 关键设计
- `EmbeddedHost` 不读 stdin、不写 stdout、不 `process::exit`（移动端单进程）
- `provider_infos()` 复用 `serve` 的 `handle_init` 逻辑（ProviderInfo 收集）
- `shutdown()` 优雅返回（绝不 exit，否则杀掉 APP）
