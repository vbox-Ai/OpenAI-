# 阶段 2 记忆点：流式 FFI + notify + Flutter 骨架

## 做了什么
- 流式 conversation FFI：
  - SDK `EmbeddedHost::conversation()`（复用 provider.conversation + SinkInner）
  - providers `FfiSink`（实现 SinkInner，chunk 转发到 C 回调）
  - `agent2api_providers_conversation_start/cancel` + 会话表
  - `Cancel::cancel` 改 pub（SDK）
- notify 事件通道：
  - `EmbeddedGateway` 加 notify 字段 + `set_notify_callback`
  - `agent2api_providers_set_notify_callback` FFI
- Flutter 骨架（flutter-app/）：
  - `lib/ffi.dart`（完整 FFI 绑定：init/infos/call/conversation/notify）
  - `lib/main.dart`（最小 UI：初始化 + provider 清单）
  - `pubspec.yaml`、`README.md`（补齐平台工程步骤 + ATS）
- CI 升级：`cargo build --release` + 上传 `.a` 产物

## 结果
- ✅ CI run #17 success（宿主 + iOS release 构建 + 产物上传）

## 踩过的坑（重要）
- 裸指针 `*mut c_void` 默认不 Send/Sync → 存成 `usize`（`UserData` newtype），
  回调时 cast 回指针。这是 FFI 跨线程回调的标准坑。
