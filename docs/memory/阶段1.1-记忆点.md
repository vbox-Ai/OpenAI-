# 阶段 1.1 记忆点：crate 拆出 lib 目标

## 做了什么
- `providers/Cargo.toml` 新增 `[lib]`：`crate-type = ["staticlib", "cdylib", "rlib"]`，name=`agent2api_providers`
- 新增 `src/lib.rs`：模块声明 + `run()` + FFI 探活函数 `agent2api_providers_ping()`
- `main.rs` 改成薄包装：`fn main() { agent2api_providers::run(); }`
- `ios-check.yml` 增加「宿主桌面 check」步骤（验证 bin + lib 双目标）

## 结果
- ✅ CI run #3 success（宿主桌面 + aarch64-apple-ios 双 check 通过）
- bin 与 lib 双目标都编译通过，桌面端行为不变

## 关键决策
- 保留 `[[bin]]` 不删，桌面端继续用；移动端走 `[lib]` 产出 staticlib
- 模块声明搬到 lib.rs，main.rs 变薄包装（避免 bin/lib 各编译一份重复代码）
