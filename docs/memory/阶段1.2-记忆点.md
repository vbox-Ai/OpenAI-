# 阶段 1.2 记忆点：EmbeddedGateway

## 做了什么
- 新增 `crates/providers/src/embedded.rs`：
  - `AccountStore` trait（8 个存储抽象方法：get / list / update / mark_limited / ledger_get / ledger_put / settings_get / settings_set）
  - `EmbeddedGateway`（实现 `CallGateway`，把回调路由到 `AccountStore`）
  - `MemoryStore`（内存占位实现，不落盘）
  - `memory_gateway()` 工厂函数
- `lib.rs` 注册 `pub mod embedded`

## 结果
- ✅ CI run #4 success（宿主桌面 + aarch64-apple-ios 双 check 通过）

## 关键设计
- `CallGateway` 是单进程化核心：把 `CallHandle`（stdio 写帧等应答）换成
  `EmbeddedGateway`（进程内直连存储），provider 代码一行不用改
- 持久层抽象成 `AccountStore` trait；真实实现（SQLite 账号/账本/设置 +
  Keychain 凭证）后续替换 `MemoryStore`
